**ProcStudio（进程工作台）** 是一款面向逆向分析人员、安全研究人员与系统开发者的全功能 Windows 进程交互、载荷注入与内存调试工作台。

软件采用纯单文件绿色便携设计（Single Portable EXE），零外部运行库依赖，免安装即开即用。深度集成了**进程多维检索与窗口准星抓取**、**4 大底层 DLL 注入模式**、**挂起拉起注入 (Spawn & Inject)**、**Shellcode 动态汇编与上下文劫持**、以及**远程虚拟内存浏览与字节补丁**五大核心能力。

---

## 🎯 典型应用场景

1. **软件与游戏 Mod / 插件加载**
   - 通过经典远程线程或手动映射（Manual Map）无缝将自研功能扩展 DLL 加载进宿主进程，支持常规启动或从初始状态挂起启动，不影响目标程序正常逻辑。
2. **安全研究与载荷动态分析**
   - 利用早鸟注入（Early Bird APC）模拟真实安全对抗场景，在目标进程尚未执行任何用户代码时提前部署监控代码；配合实时内存 Hex Dump 快速分析目标进程在不同运行阶段的内存变化。
3. **逆向工程与 Shellcode 快速验证**
   - 内置实时汇编引擎，无需启动庞大的 IDE 或第三方汇编工具，直接键入 x86/x64 汇编指令并即时向目标进程投送执行（支持创建独立线程或劫持已有线程寄存器），快速验证 PoC 与关键算法。
4. **进程热补丁与内存临时修复**
   - 无需重新编译或替换目标程序二进制文件，在程序运行过程中直接定位指定虚拟地址，强制解除代码段写保护并写入补丁字节序列，实现代码逻辑的热修复与旁路调试。

## 🌟 核心功能特性

### 1. 全局进程面板 (Process Management)

- **多标签页全局同步**：选中的目标进程在“DLL 注入”、“Shellcode 执行”、“内存编辑”三大标签页间无缝联动共享。
- **十字准星窗口秒级定位 (Crosshair Window Finder)**：按住准星图标拖动到屏幕任意窗口上方，自动高亮目标窗口边框并瞬间在列表中定位对应进程，支持“瞄准时自动隐藏主窗口”防遮挡功能。
- **全维度模糊搜索过滤**：支持通过进程名称、PID、架构（x86/x64）、会话 ID（Session ID）以及程序全路径进行实时即时筛选。
- **多列自由排序**：支持点击表头按 PID、名称、架构、会话等升降序自由排序，并带有直观指示箭头。
- **模块列表枚举**：支持一键枚举查看目标进程加载的全部 DLL 模块、基址、内存大小与物理路径。
- **特权自提与架构安全校验**：启动时自动申请并启用系统调试权限（`SeDebugPrivilege`）；严格检测目标是 64 位还是 32 位（WOW64），并在跨架构不安全时给出明确拦截与预警。

### 2. 多模式 DLL 注入引擎 (DLL Injection)

支持 **附加运行中进程** 与 **挂起启动拉起 (Spawn & Inject)** 两种执行流程：

- **挂起拉起启动**：以 `CREATE_SUSPENDED` 模式拉起目标 EXE（支持自定义命令行参数与工作目录），在目标主模块执行任何用户初始化或安全机制代码前完成注入，随后自动唤醒恢复运行。

#### 4 大注入策略特性对比

| 注入策略                             | 技术原理                                                     | 适用场景与优势                                               |
| :----------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **CreateRemoteThread + LoadLibrary** | 经典标准远程线程，调用系统 `LoadLibraryW` 加载 DLL           | 稳定性最高，兼容绝大部分常规目标与开发调试                   |
| **QueueUserAPC (Early Bird)**        | 向目标线程队列投递异步过程调用 (APC)                         | 适合与挂起拉起结合构成**早鸟模式 (Early Bird)**，规避部分线程检测 |
| **SetWindowsHookEx**                 | 安装窗口消息钩子（`WH_GETMESSAGE`），消息驱动加载            | 适用于含 GUI 窗口的目标；所有辅助钩子已全部内嵌，**无需携带外部 DLL** |
| **Manual Map (手动映射)**            | 内存直接展开 PE 节区、修复重定位、填充 IAT、执行 TLS、注册 x64 异常表 | **完全不经过系统 `LoadLibrary`**，PEB 模块链表无痕迹；支持抹除 PE 头；支持 x64 跨架构映射 x86 (WOW64) |

- **人性化交互**：支持穿透 UIPI 的 DLL 文件拖拽载入；内置下拉历史记录（MRU）与一键清空。

### 3. Shellcode 执行与实时汇编引擎 (Shellcode Runner)

- **三种输入格式自由切换**：
  - **十六进制文本**：智能解析多种格式（如 `\x90\x90`、`90 90`、`0x90, 0x90`、`90,90` 等）。
  - **Bin 镜像文件**：一键浏览或拖拽载入 `.bin` 原始 Shellcode 文件。
  - **实时汇编编写 (Live ASM)**：直接在编辑器中键入 x64/x86 汇编指令，支持一键组译预览 Machine Code。
- **双通道远程执行**：
  - **CreateRemoteThread**：在目标进程分配内存并创建全新独立远程线程执行。
  - **线程上下文劫持 (Context / RIP Hijack)**：挂起目标现有线程，劫持寄存器（RIP/EIP）指向 Shellcode 内存，执行完毕后还原线程上下文。
- **深度反馈与联动**：执行成功后弹窗详细反馈目标 PID、分配基址、分配大小与线程句柄，**支持一键跳转至“内存编辑”标签页联动查看**。

### 4. 远程内存查看与字节补丁 (Memory View & Patch)

- **虚拟地址精准定位**：支持直接输入 16 进制虚拟地址（兼容 `0x` 前缀与纯十六进制），快速定位目标进程内存空间。
- **多规格分页浏览**：支持 64B、128B、256B、512B、1024B、4096B 多种分页尺寸，支持向前翻页、向后翻页与实时刷新。
- **经典专业 Hex Dump 视图**：标准内存十六进制布局，左侧地址栏 + 中间 16 字节十六进制 HEX 视图 + 右侧 ASCII 可见字符预览。
- **安全内存补丁写入 (Memory Patching)**：
  - 配备**防误触安全确认锁**，防止误触破坏目标内存。
  - 支持对只读代码段强制打补丁：自动调用底层接口临时提权至可写，写入完成后自动恢复原保护属性。
  - 写入成功后自动重新读取目标内存并实时刷新 Hex Dump 显示。

### 5. 现代化交互与工业级品质

- **原生单文件绿色版**：所有辅助模块与汇编引擎均已打包内嵌，下载单个 `ProcStudio.exe` 即可使用全部功能，绝不在系统残留冗余文件。
- **高 DPI 细腻呈现**：全功能支持 Windows Per-Monitor V2 DPI 缩放，4K/2K 高分屏下字体与布局清晰锐利。
- **实时诊断日志系统**：底部日志栏具备多级别彩色输出与高精度时间戳，内置系统错误码（GetLastError）与 NTSTATUS 自动转中文可读解释。

## 📖 详细操作使用指南

### 一、 运行准备

1. 下载 `ProcStudio.exe`。
2. 右键单击 `ProcStudio.exe`，选择 **以管理员身份运行**（跨进程内存操作与提权必须依赖管理员权限）。

### 二、 定位目标进程

- **方式 1（搜索过滤）**：在菜单啦打开的进程列表上方的搜索框中输入进程名、关键字或 PID，单击选中目标进程。
- **方式 2（准星秒级抓取）**：在左侧面板找到“十字准星”图标，按住鼠标左键不放并拖动至屏幕上目标程序的窗口上方，松开鼠标即可秒级定位目标进程（若担心主窗口遮挡，可在顶部菜单勾选“十字瞄准时隐藏自身窗口”）。

### 三、 DLL 注入流程

1. 切换至 **“DLL 注入”** 标签页。
2. 点击“浏览”选择待注入的 DLL 文件，或直接将 DLL 文件拖拽到输入框中。
3. 下拉选择所需策略：
   - 绝大部分日常调试场景推荐选择 `CreateRemoteThread`；
   - 若目标有模块加载检测或追求隐蔽性，推荐选择 `Manual Map (手动映射)`。
4. 点击 **“执行注入”**，在底部日志窗口中查看每一步的状态与注入基址。
5. **挂起创建启动 (Spawn & Inject)**：若需在目标程序启动之初注入，选中“挂起启动注入”单选框，浏览选择目标 `.exe` 文件（可按需配置启动参数与工作目录），点击“启动并注入”即可。

### 四、 Shellcode 汇编与执行流程

1. 切换至 **“Shellcode 执行”** 标签页。
2. 选择输入格式（如十六进制文本、Bin 文件或实时汇编代码）。
3. 若选择实时汇编：直接在文本框中键入汇编指令（如 `mov rax, 1; ret`），点击“汇编预览”可确认生成的十六进制机器码。
4. 选择执行方式（`CreateRemoteThread` 或 `Context 劫持`）。
5. 点击 **“执行 Shellcode”**，成功后在弹出窗口中可点击 **“在内存面板中查看”** 直接转至该内存区域。

### 五、 远程内存查看与修改流程

1. 切换至 **“内存编辑”** 标签页。
2. 在“起始地址”栏输入欲查看的目标虚拟地址（如 `0x7FF70000`），点击 **“前往”**。
3. 点击“上一页”/“下一页”或切换每页大小进行内存巡视。
4. 若需写入补丁：勾选下方“确认写入”复选框，输入目标写入地址与 Hex 字节序列（如 `90 90 90 90`），点击 **“写入内存”** 完成热补丁。

## ❓ 常见问题解答 (FAQ)

#### Q1: 运行软件或执行注入时，杀毒软件弹出告警/报毒？

- **解答**：本工具涉及进程枚举、分配远程内存（`VirtualAllocEx`）、读写目标内存（`WriteProcessMemory`）以及创建远程执行流（`CreateRemoteThread`）等底层高危行为。这些是进程注入与调试工具的必备行为，大部分杀软会将其直接标记为高危行为或特征报毒。
- **建议**：软件已在 GitHub Release 提供官方纯净构建版本，仅供合规安全研究与开发测试，请在使用前将 `ProcStudio.exe` 添加至安全软件的信任区或白名单中。

#### Q2: 提示“无法打开目标进程”或“错误码 5 (`ERROR_ACCESS_DENIED`)”？

- **解答**：目标进程具有更高完整性级别（如系统核心服务、带有反作弊保护的游戏进程）或启用了微软受保护进程（PPL）机制。
- **建议**：
  1. 请确认是否已以**管理员身份**运行 ProcStudio；
  2. 若目标由反作弊内核驱动拦截或启用了系统级 PPL 保护，纯用户态工具无法直接穿透。

#### Q3: 为什么 64 位工具向 32 位 (WOW64) 进程注入时部分策略不可用？

- **解答**：Windows x64 环境下运行的 32 位程序运行在 WOW64 子系统内，两者的内存空间与寄存器上下文完全不同：
  - `CreateRemoteThread + LoadLibrary`：不支持跨架构（32 位进程无法加载 64 位 DLL）；
  - `Manual Map (手动映射)`：工具已深度内置跨架构手动映射，支持直接向 32 位 WOW64 进程映射 x86 DLL；
  - `SetWindowsHookEx`：工具已内嵌 32 位辅助代理，支持向 32 位 GUI 窗口正常安装消息钩子。

#### Q4: 使用本工具还需要额外安装其他运行库或携带 DLL 吗？

- **解答**：**完全不需要**。ProcStudio 采用纯单文件绿色发布，静态链接了 C/C++ 运行库，所有辅助钩子组件与汇编引擎均已直接封装在 EXE 内部，单个文件即可独立稳定运行。
